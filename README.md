# CUTLY AI

AI-powered creative editing assistant for filmmakers, editors, and creators.

## 🚧 Status

Currently in development.

## 🎯 Vision

CUTLY helps creators communicate their editing requirements using natural language and turns those instructions into intelligent editing workflows.

## ✨ Planned Features

- AI-assisted image and video editing
- Natural-language editing instructions
- Multilingual user input
- Automatic language detection
- Creative editing workflows
- Filmmaker and editor-focused tools
